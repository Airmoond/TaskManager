# Task Manager - Main Version

## 项目简介

这是我的第一周 Python 练习项目：一个在终端运行的任务管理器。你可以添加待办事项、查看进度，并在下次启动时继续管理之前的任务。项目将命令行交互、任务管理和文件读写分开实现。

## 功能介绍

| 菜单选项 | 功能 |
| --- | --- |
| `1` | 添加任务，程序会自动分配任务 ID |
| `2` | 查看所有任务的 ID、名称和完成状态 |
| `3` | 按任务 ID 修改名称 |
| `4` | 按任务 ID 将任务标记为已完成 |
| `5` | 按任务 ID 删除任务 |
| `0` | 退出程序 |

每次成功添加、改名、完成或删除任务后，程序都会自动保存。下次启动时会恢复历史任务，并继续分配新的任务 ID。

## 项目结构

```text
.
├── main.py          # 程序入口：显示菜单、处理输入和输出
├── task.py          # 定义单个任务及其完成状态
├── task_manager.py  # 管理任务集合，分配任务 ID
├── storage.py       # 将任务保存到 JSON 文件，并在启动时读取
├── .gitignore       # 忽略本地数据、缓存和编辑器配置
└── README.md        # 项目说明
```

`tasks.json` 是本地任务数据文件。没有历史数据时，程序从空列表开始，首次添加任务后会在项目目录生成该文件。该文件不提交到 Git。

## 运行方式

需要 **Python 3.10 或更高版本**，无需安装第三方依赖。

在终端进入项目目录，运行：

```bash
python main.py
```

看到菜单后，可以先输入 `1` 添加一条任务，再输入 `2` 查看任务列表。输入 `0` 退出。

## 技术栈

- **Python 3.10+**：使用类组织任务和管理逻辑，使用 `match/case` 处理菜单选项。
- **`json`**：读写本地任务数据。
- **`pathlib`**：定位项目目录下的 `tasks.json`。
